СВОИ ПРИНТЫ НА МАЙКАХ
=====================
Положите сюда картинки PNG (лучше квадратные, с прозрачным фоном, примерно 256x256):

  1.png — Чёрная майка      5.png — Синяя майка
  2.png — Оранжевая майка   6.png — Зелёная майка
  3.png — Белая майка       7.png — Жёлтая майка
  4.png — Красная майка     8.png — Фиолетовая майка

Картинка заменит стандартную эмблему спереди и сзади майки.
После добавления просто обновите страницу в браузере (F5) — сервер перезапускать не нужно.
Картинки нужны только на компьютере, где запущен сервер: друзья получат их автоматически.
